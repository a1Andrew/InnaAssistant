# InnaAssistant

Персональний AI-асистент у Telegram для Інни: одна система, в якій зібрані всі напрямки —
робота з командою, проєкти, Instagram-контент, тіло, навчання, побут. Замість
блокнота: асистент сам записує, сам розставляє пріоритети на день, у неділю дає
аналіз тижня, 1-го числа — зріз місяця. Звертається до господині на ім'я, імена
в задачах — це її команда (ім'я змінюється в `.env`, `ASSISTANT_OWNER_NAME`).

Бот працює на Claude (Anthropic API), зберігає все у власній базі SQLite і
**не має доступу до сервера**: ні bash, ні читання файлів. Максимум, що він
може зробити, — записати рядок у свою базу.

---

## 1. Що він уміє

| Напрямок | Приклад повідомлення | Що станеться |
|---|---|---|
| Свої задачі | «договір для клієнта до п'ятниці, терміново» | задача Інни з дедлайном і пріоритетом A |
| Задачі команді | «Ім'я — підготувати позов до вівторка» | задача на людину з команди; «що там по ній?» покаже, що на ній висить |
| Контент | «рілс про докази — 12к переглядів, 300 збережень» | метрики в контент-план, підуть в аналіз тижня |
| Контент-план | «зроби план на тиждень: 3 рілс і 2 пости по темі суду» | 5 записів у плані з датами |
| Тіло | «ноги 50 хвилин, вага 58.4» | два записи в щоденник, динаміка по тижнях |
| Навчання | «англійська 45 хвилин, present perfect» | регулярність видно в підсумках |
| Цілі | «ціль на місяць — 10к підписників» | ціль з метрикою, прогрес питає сам |
| Нагадування | «нагадай завтра о 10 подзвонити в суд» | напише в чат у цей час |

Сам пише без запиту:

* **08:30** — план на день: 3-5 головних справ, дедлайни, що висить на людях;
* **21:00** — підсумок дня: що закрито, що переносимо;
* **неділя 19:00** — аналіз тижня по всіх напрямках;
* **1-ше число 10:00** — зріз місяця і 3 пріоритети на наступний.

Час і часовий пояс міняються в `.env` (`MORNING_AT`, `EVENING_AT`, `WEEKLY_AT`,
`MONTHLY_AT`, `ASSISTANT_TZ`) без правок коду.

## 2. Група з темами

Щоб усе не змішувалось в одну стрічку, бот розкладає напрямки по темах
(Topics) у груповому чаті. Що написано в темі «Контент» — іде в Instagram,
що в «Тіло» — у щоденник тіла. Плани приходять у «🌅 План дня», підсумки — у
«📊 Підсумки».

Як налаштувати:

1. Створити групу в Telegram → додати туди її та бота.
2. Налаштування групи → **Теми (Topics)** → увімкнути.
3. Зробити бота **адміном** з правом «Керувати темами».
4. Написати в групі `/setup` — бот сам створить теми:
   🌅 План дня, 📋 Наша робота, ⚖️ Проєкти, 📸 Контент, 💪 Тіло, 📚 Навчання,
   🏡 Побут, 📊 Підсумки, 💡 Ідеї.
5. Під окремий великий проєкт — `/newtopic Право і порядок`.
   Прив'язати вже наявну тему до напрямку — `/bind Instagram` усередині теми.

> **Важливо.** У групах Telegram за замовчуванням ховає від ботів звичайні
> повідомлення. У @BotFather: `/mybots` → бот → *Bot Settings* → *Group Privacy*
> → **Turn off**. Без цього бот у групі бачитиме лише команди.

В особистому чаті все теж працює — просто без поділу на теми.

## 3. Команди

```
/today     план на день            /tasks     відкриті задачі
/evening   підсумок дня            /content   контент-план
/week      аналіз тижня            /goals     цілі
/month     зріз місяця             /projects  напрямки
/setup     розгорнути теми         /export    вся база одним файлом
/newtopic  нова тема               /reset     почати діалог заново
/bind      тема → напрямок         /info      стан системи
/topics    список тем              /id        мій Telegram ID
```

`/tasks`, `/content`, `/goals`, `/projects` читають базу напряму — миттєво і
без витрат на модель. Решта — через асистентку.

## 4. Установка на сервер

```bash
cd /root
git clone https://github.com/a1Andrew/InnaAssistant.git
cd InnaAssistant
python3 -m venv venv                  # на Ubuntu 24.04 без venv pip лається
venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env
```

Мінімум, що треба заповнити в `.env`:

```ini
ANTHROPIC_API_KEY=sk-ant-...
ASSISTANT_BOT_TOKEN=          # ОКРЕМИЙ бот з @BotFather
ASSISTANT_OWNER_ID=595153958  # чия це база: усі записи лягають під нього
ASSISTANT_OWNER_NAME=Інна     # бот звертається до неї на ім'я
ASSISTANT_USER_IDS=595153958  # хто може писати боту: її ID + твій через пробіл
```

Дізнатись свій Telegram ID: написати боту `/id`.

Запуск як сервіс:

```bash
sudo cp deploy/inna-assistant.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now inna-assistant
journalctl -u inna-assistant -f
```

Оновлення:

```bash
cd /root/InnaAssistant && git pull && sudo systemctl restart inna-assistant
```

Резервні копії бази (раз на добу, зберігаються 30 днів):

```bash
crontab -e
0 4 * * * /root/InnaAssistant/deploy/backup_db.sh
```

## 5. Дані і безпека

* Усе лежить у `inna_assistant.db` поруч зі скриптом. Файл у `.gitignore` — у git не їде.
* `/export` віддає всю базу одним JSON — можна забрати собі в будь-який момент.
* Доступ лише за Telegram ID зі списку. Чужі в групі ігноруються мовчки.
* У бота немає bash, немає читання файлів, немає доступу до `.env` і до сервера.
* Історія діалогу коротка і живе в пам'яті процесу; **дані живуть у базі**, тому
  перезапуск сервісу нічого не втрачає.

## 6. Перевірка після змін у коді

```bash
venv/bin/python tests/test_assistant_data.py    # база, інструменти, зрізи
venv/bin/python tests/test_assistant_loop.py    # цикл агента із заглушкою API
```

Обидва працюють на тимчасовій базі й не ходять у мережу.

## 7. Скільки це коштує

Модель за замовчуванням — `claude-opus-5` (найсильніша: якісніші пріоритети і
аналітика). Якщо захочете дешевше, у `.env`:
`ASSISTANT_MODEL=claude-sonnet-5` — приблизно вдвічі-втричі дешевше за токен,
для щоденних записів різниця майже непомітна. Основні витрати — ранковий план,
вечірній підсумок і тижневий аналіз (кілька звернень на день).
